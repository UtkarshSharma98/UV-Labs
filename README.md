# UV Labs

**Building technology for a better tomorrow.**

UV Labs is an emerging technology initiative focused on building innovative, accessible, and practical digital solutions.

## 🚀 Currently building: UV EdTech

We are currently working on **UV EdTech**, a student-focused educational platform designed to make learning more accessible, organized, and engaging.

Our initial focus is on pharmacy students. We are actively developing the platform, its learning experience, and student-focused tools.
